Практическая работа по дисциплине "Шаблоны проектирования".
Цель работы: Сформировать у студента навык распознавания типовых проблем проектирования в существующем коде, выделения «точек изменчивости», формулирования гипотез улучшения дизайна и подготовки рабочего окружения для дальнейших практических работ по порождающим паттернам. По итогам занятия студент должен уметь объяснить, почему текущий дизайн хрупкий, какие ответственности смешаны, какие зависимости следует разорвать, и как организовать проект так, чтобы его было удобно расширять и тестировать.

Технологии и инструменты:
- Python 3.13.13
- pytest-9.0.3
- GitHub
- PlantUML

Зависимости:
- requirements.txt
- pytest.ini

Тестирование:
Для запуска тестирования необходимо клонировать проект в среду разработки (например, Visual Studio Code), иметь упомянутые выше технологии, перейти на вкладку Testing и запустить тесты. Терминал покажет результаты тестирования.

Файл config.yaml используется для конфигурации приложения без правки кода. Описание файла:
dataSourceType - может принимать значения: db (база данных), file (файловое хранилище), web (внешнее API)
filePath - путь для file
apiUrl - адрес API для web
